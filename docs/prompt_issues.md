# Prompt & Extraction Issue Log

This is the running log for known issues with the AI extraction step (`ai_translate` / `ai_classify` / `ai_query` in the silver layer) and the entity-matching logic built on top of it. It is referenced directly from the pipeline code — `scripts/silver/08_silver_company_test.dbquery.ipynb`, `scripts/silver/12_silver_quality_check.dbquery.ipynb`, and `scripts/gold/09_gold_bridge_table_quality_checks.ipynb` all point here when a check surfaces something that needs a human decision rather than a code fix.

**When to add an entry:** a quality check returns an unexpected row, a company-name candidate in `datasets/review/07_company_candidates.csv` turns out to be an extraction artifact rather than a real company (see `docs/business_rules.md`, BR-CO-05), or you spot a recurring pattern the extraction prompt gets wrong. Give it the next `PI-NNN` ID, don't reuse IDs, and update the status in place as it moves from `Open` to `Mitigated`/`Resolved` rather than deleting the row.
